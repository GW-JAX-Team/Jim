inject_signal(waveform_model, parameters: dict[str, float], allow_wraparound: bool = False) -> tuple[FloatScalar, ComplexScalar] ¤

Add a signal to the data of the detector.

The signal is cut to the frequency range of the data and added in the frequency domain to whatever the detector holds: zero data, noise, real data or earlier signals. Call it again to add more signals.

Note: The detector needs a PSD and data beforehand. set_zero_noise and simulate_and_set_noise create the data with the frequency range that the injection needs; for other data, such as real data, set data.frequency_bounds first. The trigger time is that of the data (Data.trigger_time), by default 2 s before their end.

Parameters:

Name Type Description Default
waveform_model

The frequency-domain waveform model to be injected.

 required
parameters dict

Likelihood-space source parameters: those of the waveform model (waveform_model.parameter_names) and ra, dec, psi and t_c.

 required
allow_wraparound bool

The waveform has no time axis, so a signal that does not fit the segment wraps around in it. By default that is an error; with True it is a warning. A conservative inspiral-duration estimate and merger margins check compact-binary signals requiring M_c and eta. Other models need an explicit override because their duration cannot be estimated this way. Defaults to False.

 False

Returns:

Name Type Description
tuple tuple[FloatScalar, ComplexScalar]

The optimal SNR of the signal, and its matched-filter SNR against the data including the signal, noise and earlier signals.

Raises:

Type Description
ValueError

If the detector has no PSD or no data, if the PSD is not finite and positive over the frequency range of the data, if the range does not start above 0 Hz or holds fewer than two frequencies, if the trigger time of the data is not inside them, if a parameter is missing or eta is not in (0, 0.25], if the signal has no finite, positive signal-to-noise power, if a time-domain model is supplied, or if its estimated duration does not fit the segment or cannot be estimated. The detector is unchanged then.

GroundBased3G ¤

Bases: GroundBased2G

Ground-based detector with a frequency-dependent response.

With earth_rotation, the response follows the Earth's rotation while the signal is in band, which matters for signals that stay in band for ten minutes or longer. It needs M_c, eta, s1_z and s2_z among the parameters passed to fd_response.

With finite_arm_length, the arms are not assumed to be short compared to the gravitational wavelength, which matters for loud signals with power at high frequencies. Its phase convention is given in the technical notes of the documentation.

With both switched off, the response is identical to GroundBased2G.

Arm length in meters, used by the finite-arm-length response.

get_ET_2L(*, alignment_angle: float = 42.5, earth_rotation: bool = False, finite_arm_length: bool = False) -> list[GroundBased3G] ¤

Return the two L-shaped detectors of the Einstein Telescope 2L design.

The design has two L-shaped interferometers with 15 km arms, ET_Sar in Sardinia and ET_EMR in the Euregio Meuse-Rhine. The arms of ET_Sar have the azimuths of the Virgo arms. The arms of ET_EMR are rotated from those of ET_Sar by alignment_angle, a difference of azimuths, each measured against the local axes of its site rather than the great circle between them.
